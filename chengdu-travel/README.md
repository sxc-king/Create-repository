# 途伴 JourneyMate・旅程优先的全链路旅行服务平台

基于 **Vue3 + Vite + TailwindCSS** 构建。由「成都文旅推荐站」升级改造为 **「以旅程为中心、AI 全程随行、同行协同」** 的旅游服务平台（对标 MD《旅游伴侣》的 V1.0 落地）。成都本地内容作为可复用的「资源 / 商品池」。

## 快速开始



```
# 1. 安装依赖
npm install

# 2. 启动开发服务器（端口 5174）
npm run dev
# 访问 http://localhost:5174/

# 3. 生产构建（输出 dist/ 目录）
npm run build

# 4. 本地预览构建产物
npm run preview
```

## 核心模块（V1.0）



| 路由             | 模块       | 说明                                                                |
| -------------- | -------- | ----------------------------------------------------------------- |
| `/`            | 首页（旅程优先） | 首屏「开启新旅程 + 我的旅程」，弱化快速预订，灵感模板推荐，保留热门景点 / 笔记                        |
| `/trips`       | 我的旅程中心   | 草稿 / 待出发 / 进行中 / 已结束 状态分组，旅程卡片                                    |
| `/trips/new`   | 新建旅程     | 基础信息（目的地 / 日期 / 预算 / 标签）+ AI 帮我规划 / 空白自建                          |
| `/trip/:id`    | 旅程详情     | 时间线编辑器 + AI 随行侧边管家 + 同行协同面板 + 关联订单面板 + 工具箱（导出 PDF / 分享 / 复刻 / 归档） |
| `/ai`          | AI 旅行管家  | 多轮对话，生成 2 版方案（休闲 / 紧凑）、询价卡片、风险提示、采纳存入草稿                           |
| `/inspiration` | 灵感广场     | 行程模板分类浏览 + 一键复刻为草稿                                                |
| `/orders`      | 订单中心     | 订单列表（全部 / 待支付 / 已支付 / 已完成 / 已取消），跳转所属旅程                           |
| `/profile`     | 个人中心     | 出行偏好（AI 参考）、收藏、节点评价管理                                             |
| `/messages`    | 消息中心     | 行程通知 / 同行邀请 / 订单通知 / AI 消息聚合，未读标记                                 |
| `/stay` 等      | 成都玩法（保留） | 住宿 / 美食 / 购物 / 玩乐 / 当地向导 / 攻略 资源库                                 |

## 产品理念



* **旅程是一等公民**：订单是旅程的子资源（订单绑定 `journeyId`，预订自动回写旅程服务节点）

* **AI 分层**：售前 AI 规划 → 售中 AI 随行管家 → 售后记忆 / 评价（演示版为前端规则式生成）

* **同行协同**：权限（可编辑 / 仅查看 / 仅通知）、评论、跨天移动节点

* **隐私**：旅程默认私密，分享链接手动生成

## 技术要点



* Vue 3 组合式 API + Vue Router 4（16 条路由，懒加载分包，标题随路由）

* Vite 6 + TailwindCSS 4

* 数据持久化：旅程 / 订单 / 消息 / 偏好 / 收藏 / 评价存 `localStorage`，刷新不丢失

* 数据层：`store/trip.js`（旅程 CRUD）、`store/order.js`、`store/message.js`、`store/user.js`（扩展偏好 / 收藏 / 评价）

* AI 引擎：`ai/assistant.js`（规则式行程生成，供 /ai 与旅程内 AI 随行复用）

* 灵感模板：`data/templates.js`（6 套成都行程模板）

* 登录：演示账号 `admin` / `123456`

## 目录结构



```
chengdu-travel/
├── src/
│   ├── ai/assistant.js          # AI 行程生成引擎
│   ├── store/                   # trip / order / message / user 状态
│   ├── data/                    # 站点数据 + 灵感模板
│   ├── components/              # TripCard / AICompanion 等 + 原组件
│   ├── views/                   # 旅程中心/AI/灵感/订单/个人/消息 + 原栏目页
│   └── router/index.js          # 16 条路由
```

## 说明



* 评分、点评数、价格为站点展示示意数据；AI 方案为前端规则生成，不承诺实时库存与价格，均标注「以供应商实时查询为准」。

* 生产构建产物在 `dist/`，可部署到任意静态服务器（history 路由需回退到 `index.html`，或改用 hash 路由）。
